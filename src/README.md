# 设计源码

对应比赛规则第 3.3.5.1 和 3.3.5.4 节，保存本项目实际采用的 RTL、HLS 和 PS 侧源码，以及离线训练与软件参考实现。

## 计划内容

- EfficientAD 局部教师-学生分支的离线训练、推理和轻量化实现。
- INT8 权重与激活量化、校准和参数导出。
- 卷积、逐点特征平方差、通道累加等 RTL/HLS 加速单元。
- PS 侧数据组织、加速器调用、几何约束判定、结果显示与记录。

实现时需写明网络与输入尺寸、张量布局、数据类型、量化尺度、PS/PL 分工和接口契约。采用何种实现方式由基线和资源评估决定。

目前已有 `score_map.py`：给定同尺度的教师和学生特征 `[C,H,W]`，产生逐点平方差按通道平均后的局部异常图 `[H,W]`。浮点版按公式输出；INT8 参考版在宽位计算差与平方后做整数除法，返回整数分数。该文件不负责训练、网络推理、特征尺度对齐、阈值选择、缺孔判定或板端加速。使用和验证命令见根目录 `README.md`。

教师/学生网络结构、权重来源及其 FPGA 部署仍待选择和验证。

`image_baseline.py` 是独立的固定机位灰度像素模板基线：读取正常参考图片和待测图片，复用 `score_map_float` 计算逐像素平方差，经阈值和四连通区域面积过滤后保存结果。它不训练模型、不判断异常类型，也不等同 EfficientAD。命令和限制见根目录 README。
