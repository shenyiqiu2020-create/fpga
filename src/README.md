**2026-10-27 后续级联候选：** [`tie_mount_relocate.py`](tie_mount_relocate.py)仅在旧裁剪与 1.30 倍原图重裁均未通过严格轮廓门时，从哈希核对的完整原 JPEG 补 5% 背景画布重新定位。新版 [`tie_mount_shape_rf.py`](tie_mount_shape_rf.py)再用严格主路和带低质量标记的宽松边界二级随机森林为当前 344 张任务内照片全部给出二元输出；先前 17 张失败照中 16 张被重定位救回，最后 `D32_0108` 一张走二级。实验仍须新实物验收，不改变完整 EfficientAD 或 B/C 数值包。指标与命令见[级联候选记录](../report/shape_cascade_candidate_20261027.md)；下方记述上一版 327 张候选。

对应比赛规则第 3.3.5.1 和 3.3.5.4 节，保存本项目实际采用的 RTL、HLS 和 PS 侧源码，以及离线训练与软件参考实现。

## 计划内容

- EfficientAD 教师、学生与自动编码器相关分支的离线训练、完整推理和经验证的轻量化实现。
- INT8 权重与激活量化、校准和参数导出。
- 卷积、逐点特征平方差、通道累加等 RTL/HLS 加速单元。
- PS 侧数据组织、加速器调用、几何约束判定、结果显示与记录。

实现时需写明网络与输入尺寸、张量布局、数据类型、量化尺度、PS/PL 分工和接口契约。采用何种实现方式由基线和资源评估决定。

目前已有 `score_map.py`：给定同尺度的教师和学生特征 `[C,H,W]`，产生逐点平方差按通道平均后的局部异常图 `[H,W]`。浮点版按公式输出；INT8 参考版在宽位计算差与平方后做整数除法，返回整数分数。该文件不负责训练、网络推理、特征尺度对齐、阈值选择、缺孔判定或板端加速。使用和验证命令见根目录 `README.md`。

电脑端完整 EfficientAD 的候选实现与权重来源已在[数值交接](../report/bc_handoff_20261026.md)固定；教师、学生和自动编码器在 Zynq 上的实际部署、资源与性能仍待 B/C 验证。

团队已完成公开 `bottle` 类初步电脑端验证、自采件完整 EfficientAD 训练与数值交接，并新增外缘辅助候选；完整单张推理入口在 `sim/`，外部网络代码、权重与训练结果在 Git 忽略的 `build/work/`。后续须用独立新实物确认算法，再根据资源预算把完整图像到判定链路迁到 ALINX Zynq 板端。本目录尚无 FPGA 加速器或板上运行程序，阶段判据见[迁移计划](../report/efficientad_plan.md)。

`image_baseline.py` 是独立的固定机位灰度像素模板基线：读取正常参考图片和待测图片，复用 `score_map_float` 计算逐像素平方差，经阈值和四连通区域面积过滤后保存结果。它不训练模型、不判断异常类型，也不等同 EfficientAD。命令和限制见根目录 README。

`tie_mount_crop.py` 是自采扎带座正面照片的首版定位裁剪：输出 `256×256` 图片和原图裁剪框。`D03` 的绿色斜放补拍图曾因固定留白比例而被误拒，现可保留完整外缘与断口；棕色正放补拍图也已通过人工检查。新版会拒绝旧的贴边图和未完整入镜的近拍，但也拒绝一张此前通过的 `D02` 左边界余量不足图。**脚本成功返回不等于照片合格，必须人工检查完整外缘和缺陷。** 它只在有足够颜色/亮度反差且工件完整入镜时使用；未证明对任意背景、侧视、遮挡或强过曝有效。保留原图及裁剪框，后续异常位置必须能映射回原图。

`tie_mount_outline.py` 是 2026-10-25 新增的**首版外缘缺损几何基线**：调用上述裁剪器，用白色前景搜索方形在图像平面内的方向，再比较四角占用量。运行 `python -m src.tie_mount_outline <照片路径>` 可得到分数、临时判定及疑似缺损角的原图坐标。当前本机两件正常与 `D01`/`D02` 的 8 张棕色背景照片已作流程检查；默认阈值 `0.35` 从这批图试用，尚未在独立验证件上定标。它只针对缺角/边缘缺口，**不检测 `D03` 斜肋断损**；也不证明对任意背景、光照或透视有效。与 EfficientAD 候选模型的结果须分开报告。

按原作品简介，EfficientAD 的教师–学生、自动编码器与异常图融合仍是主实现目标；`tie_mount_outline.py` 只提供独立辅助对照。当前没有把几何评分接入 EfficientAD 的训练或最终判定，也没有证明 EfficientAD 已适应任意平面方向。

**2026-10-27 外缘辅助候选：** [`tie_mount_shape_rf.py`](tie_mount_shape_rf.py)在现有 `256×256` 工件裁剪图上，用图像边缘的背景色和中央工件种子初始化 GrabCut，再提取外轮廓、旋转矩形、凸包和凹陷的 19 项特征供小型随机森林分类。它另需 `requirements-shape.txt` 中的 OpenCV 和 scikit-learn 训练依赖，实验模型尚未作为默认模型或交付给 B/C。分割不可靠时返回 `unavailable`；概率接近分界可返回 `uncertain`，不能把两者记作正常。[`tie_mount_shape.py`](tie_mount_shape.py)是独立的纯 NumPy/Pillow 外缘凹陷位置候选，未获精确位置真值验证。`do3/D03` 为内部肋条断损，不进入首版外缘缺损训练与计分。分组验证和适用条件见[形状辅助候选记录](../report/shape_assisted_candidate_20261027.md)。
