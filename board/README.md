## 图像输入与算法部署顺序（2026-10-27）

板端目标是读取一张完整正面工件照片，执行预处理、完整 EfficientAD 推理、经验证的 PL 加速、异常图融合与正常/缺损判定，并保存结果和实测耗时。A 已提供电脑端 3000 步完整 EfficientAD 的[模型与黄金张量交接](../report/bc_handoff_20261026.md)；新增[外缘轮廓级联](../report/shape_cascade_candidate_20261027.md)仍是未通过新实物独立验收的电脑端辅助候选，训练模型 JSON 未随 Git 分发。板端不得仅运行辅助分类器却报告为完整 EfficientAD 上板。

B 先确认整板型号、版本、板端系统和文件读写，以预存图片及两份黄金样本打通 PS/PL 数值链路；C 提供加速算子和比对证据。实时摄像头作为后续输入方式：核对实际板卡接口、驱动与帧格式后再取帧，仍按同一预处理和推理规则输出判定。模型训练、阈值调整与版本冻结在电脑端进行，板端只加载经确认的模型并推理；新实物、新灯光和新背景须另做独立验收。课程版 RISC-V SoC 与竞赛版 Zynq PS/PL 分别构建和验收。
