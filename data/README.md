# 测试数据与参考结果

对应比赛规则第 3.3.5.1 和 3.3.5.4 节，保存可用于复现的测试输入、划分清单、标注、量化校准数据和黄金参考。

## 数据组织要求

- 登记工件种类、成像分辨率、照明与定位条件。
- 区分正常样本、局部破损、缺角、缺孔等缺陷样本。
- 明确训练、验证、测试与量化校准划分，说明划分方法和样本数量。
- 标注缺陷区域或几何参考，说明异常阈值和统计指标如何确定。
- 黄金参考应注明生成脚本、参数、模型权重版本和文件校验值。
- 数据、预训练权重和其他第三方资源注明来源、授权及获取方法；不能随仓库分发的内容需给出可复现的获取步骤。

大规模数据和模型文件应先评估仓库存储方式。用于复现的必要输入不能仅存在于个人机器而没有获取说明。

当前未添加样本、权重、标注或参考结果。
