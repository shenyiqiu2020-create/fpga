# 展示视频拍摄脚本

本脚本用于组织演示，不声称第 3.3 节规定了统一视频时长。建议拍成约 2 至 3 分钟，最终服从赛事补充通知。

| 镜头 | 建议时长 | 展示内容与讲述依据 |
|---|---:|---|
| 实物和输入 | 15 秒 | 同框拍摄固定座、开发板、电源与 JTAG；说明对象是白色扎带固定座，采用固定光照俯拍 |
| 架构 | 20 秒 | 展示完整 Teacher/Student/Autoencoder，强调 22 Conv 与 7 Resize 在一个可复用 PL 核执行，ARM 调度并评分 |
| 初始化 | 15 秒 | 网页选择 FPGA 后端并初始化，展示绿色已就绪状态；不把电脑参考模式称为 FPGA |
| 缺陷图片 | 25 秒 | 选择 D19_01 或实际上传图片，点击开始，等待真实执行进度，展示异常分数、热图和判定 |
| 正常图片 | 20 秒 | 换正常图片，再次实际运行，显示合格结果；说明样例用于部署校验，不代表独立精度 |
| 性能与资源 | 25 秒 | 展示测试与性能页及 Vivado 实现，说明核调用 1.484 s、演示板端约 1.713 s、JTAG 传输另计；DSP203/BRAM57 |
| 复现和边界 | 20 秒 | 展示目录、报告与技能包，说明284张回顾测试与75张板测；扩批准确率66.67%、正常误报仍待改进，海报按官方模板另做 |

拍摄前关闭无关窗口、消息通知和个人信息。点击右上拍摄模式，再按 F11；如果用内置录制，选择本标签页并在停止后确认本地 WebM 文件正常播放。不要剪掉足以改变推理耗时观感的等待时间；若加速回放，应在字幕明确标注。

前端自动化已验证真实 FPGA 运行、参考模式、文件上传、热图切换、导出和窄屏布局。物理摄像头与真实屏幕录制尚须本人授权检查；不在后台自动开启摄像头或录屏。
