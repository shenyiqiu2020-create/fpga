# 报告与交接资料

对应比赛规则第 3.3.5.3 和 3.3.5.4 节，保存设计依据、实现与优化过程、复现说明以及大模型协作记录。

**当前阅读顺序（2026-10-27）：** 先看[项目工作交接](team_outline.md)中的现行状态，再看[外缘级联候选](shape_cascade_candidate_20261027.md)的当前电脑端证据和独立验收限制；[完整 EfficientAD 的 B/C 数值交接](bc_handoff_20261026.md)与[板端迁移计划](efficientad_plan.md)分别用于系统集成。旧 300/1000 步和 327 张候选记录保留在[进度记录](progress.md)及各实验报告中，不应再写成最新准确率。2026-11-01新增[完整EfficientAD板测与计算核报告](efficientad_pl_kernel_20261101.md)：两张预存图完整推理已验证，最新含自检约5.04秒/图；摄像头与独立精度仍待验证。

## 设计报告应包含

1. 选题背景、规则工件的检测需求、已有方法和创新点。
2. 检测流程、功能框图、EfficientAD 教师/学生与自动编码器分支的设计原理；外缘级联若最终采用，另列其辅助作用、独立验证和与主算法的接口。
3. PS/PL 划分依据、网络轻量化、量化策略及接口设计。
4. 硬件、工具和依赖版本；采用非推荐工具版本时说明原因。
5. 功能验证、误差分析、板级实测及与基线的比较。
6. 优化前后性能与资源对比，说明参数、数据和测试条件。
7. 技能包的经验来源、验证过程、效果与适用边界。
8. 从零开始的完整复现步骤，给出各阶段命令与预期输出。

## 大模型协作记录应包含

- 任务背景与提示词。
- 模型回答及其中提出的假设。
- 实际验证、失败现象和修改依据。
- 自我纠错轨迹及最终采纳的方案。
- 智能体工作流设计（如实际采用）。

记录应关联具体源码版本与验证证据。性能指标与测试结果填写实际数据，未完成部分标记为待验证。
