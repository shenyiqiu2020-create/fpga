# 已验证的失败案例

| 触发条件 | 观察 | 定位和处理 | 验证边界 |
|---|---|---|---|
| GP0 AXI 打开但未接 ACLK | BD 41-758 | 不需要 PL 外设时关闭 GP0；需要时把有效 FCLK 同时接到总线与接口时钟 | Validate Design 不等于上板通过 |
| 只刷新 IP 版本或复用旧构建目录 | 修改源码后可能仍使用旧导出 | 新建 solution 和工程，逐项核对 RTL 字节身份 | 工具生成的仿真死锁检测代码须单独识别，不能任意忽略差异 |
| PE32 直接扩大为 PE40 | 并行度增加 25%，核耗时只减少 5.8%，首层变慢 | 检查通道补齐、处理批次和后处理开销，再调整任务重叠 | 并行度不能直接当作整网速度 |
| 1280-bit 浅 FIFO 使用默认存储实现 | HLS 估计额外占 72 个 BRAM18 | 显式绑定 LUTRAM；把池化状态留在消费者中，消除跨调用输入依赖 | 必须重新做 C/RTL 和布线时序 |
| 新 XSDB 会话立即检查目标 | 偶发找不到已连接的 APU | 等待目标发现并设置截止时间，始终校验线缆序列号 | 不能将目标发现延迟当作板卡掉线 |
| XSDB 2025.2 二进制写入省略字数 | 命令帮助允许省略，但本机实现返回参数数量错误 | 对 524288 字节输入显式提供 131072 个 32-bit 字 | 换版本后重新核对单位和读回内容 |
| 只根据两张标定图通过就宣称识别准确率 | 两图数值一致但样本已参与量化标定 | 将一致性与独立精度分开，并按实物分组排除 D19、N17 | 需完整独立图片与真实标签才能估计精度 |

原始 C/RTL、Vivado 和板测日志见 `sim/results/` 与 `board/evidence/`；新网页上传链路的完整异常图比对见 `sim/results/demo_board/validation.json`。
