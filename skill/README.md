# 可复用技能包

对应比赛规则第 3.3.5.2 和 3.3.5.4 节。将开发及大模型协作中经验证的经验整理为其他队伍可以复用的材料。

技能包可以采用提示词工作流、工程模板、校验脚本或结构化排错清单。若实际采用 PYNQ，可进一步提炼不绑定本题目或单一板卡的 Overlay、DMA 或黄金参考比对经验；这类通用 PYNQ Skill 在规则中另行加分。

## 每项技能的说明模板

1. **适用范围**：解决什么问题，需要哪些环境、器件或接口条件。
2. **使用方法**：可执行步骤、输入、参数与预期输出。
3. **经验来源**：来自哪些实际失败、观察或大模型协作纠错。
4. **已验证效果**：验证环境、测试方法和结果，引用真实证据。
5. **失效条件**：不适用的场景、前提变化和已知限制。
6. **复用边界**：换题目或换板卡时需要修改哪些内容。

## 后续可整理方向

- 定点量化与黄金参考比对流程。
- 卷积或流式算子接口契约及验证模板。
- 资源、时序与数据搬运瓶颈排查流程。
- 由软件基线推导 PS/PL 划分的提示词工作流。

上述方向为计划，尚未形成或验证技能。补充真实验证记录后再声明其有效性。
